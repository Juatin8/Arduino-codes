# 【00 猫耳计划改进计划】

目标：12 个月 App 内购流水 **¥10 万**（约 1,100–1,300 付费用户）。  
执行版：先让试用看见进步，再只做耳蜗/助听器获客，第 5 月达线后再涨价。  
不要做：Android、微信小程序、医院招标、英语投放、儿童主路径、买信息流。

每周只看：安装 / 测评完成率 / D3 留存 / 试用→付费 / 流水（年/月/买断拆开）。

---

## 0 原则（对照，不勾）

- 先修付费路径，再谈量和价
- 获客只做「开机 / 新配助听器 / 电话听不清」
- 主推包年，买断降温
- 12 个月只做能抬付费率或复购的功能

---

## 1 P0 产品｜第 1–6 周（不做完不投流）

- [ ] 付费墙改成 **7 日全模块试用**，到期才弹年费
- [ ] 浏览 / 试听 / 看报告 **不扣红心**（取消点进模块就扣）
- [ ] 红心包保留，但不当主付费路径
- [ ] 做 **10 分钟分级测评**（安静词、噪声词、电话句、声调）
- [ ] 测评结束页：正确率、弱项、建议每天 12 分钟
- [ ] 报告可 **分享海报 / 长图 / PDF**
- [ ] 第 7 日同一组题 **复测对照**（绿/红箭头）
- [ ] 付费墙跟在复测图后面，不跟在启动页
- [ ] 复测变好或连练 3 天，再弹系统求评
- [ ] 能降系统则把最低版本从 iOS 17 降到 **15/16**

---

## 3 定价 A｜第 1–4 月（价不动，改包装）

- [ ] 商店主按钮改成 **包年 ¥68**（文案：每天不到 2 毛）
- [ ] 包月 ¥18 保留，文案：先练一个月
- [ ] 买断 ¥128 缩到第三位，写清「含当前题库，不含以后新模块」
- [ ] 不主推家庭共享（会吃掉 IAP）

---

## 4 评分与种子｜第 1–4 月

- [ ] 求评只在进步时刻弹出
- [ ] 招募 **20 个种子用户**：免费年费 ↔ 1 条真实评价 + 1 张前后对比（知情同意）
- [ ] 90 天内凑 **25+ 条中文 4 星以上评价**
- [ ] 第 2 月末评分 ≥ **15** 条
- [ ] 差评（红心）先改产品再回复，不写好评脚本、不刷评

---

## 5 获客｜第 3 月起稳定（不买信息流）

预算全年 0–8000 元（麦、小礼品），不买安装。

### 5.1 内容（目标约占付费 55%）

- [ ] 小红书 / 视频简介写上 **人工耳蜗、助听器、听能训练**（不要只写猫耳）
- [ ] 小红书 **3 条/周**，短视频 **2 条/周**
- [ ] 选题只做：开机第 N 周电话听不清
- [ ] 选题只做：新配助听器，饭馆对话怎么练
- [ ] 选题只做：2 分钟噪声测词（带报告截图）
- [ ] 选题只做：对比电脑版天使语训，手机 12 分钟电话训练
- [ ] 外链用商店自定义页，不用「猫耳」当投放词

### 5.2 社群（目标约占付费 30%）

- [ ] 耳蜗 / 语后聋 / 助听器社群发测评说明，不硬广
- [ ] 给康复师/听力师 **打印用周报模板**
- [ ] 请老师推荐开机 1–6 个月成人，先求 **10 个真实试用**（不谈分成）

### 5.3 商店页（评分起来后才有用，约占 15%）

- [ ] 自定义产品页：开机后 30 天
- [ ] 自定义产品页：听不清电话
- [ ] App Analytics 盯搜索词：人工耳蜗、耳蜗训练、听能训练、助听器康复
- [ ] 展示涨、下载不涨 → 只改截图 1 和副标题
- [ ] 词没展示 → 检查名称/关键词，或评分仍太少

## 8 节奏与停损

- [ ] M1–2：P0 + ASO + 能降 iOS 就降｜流水 0.6 万｜付费 80｜评 15
- [ ] M3–4：内容稳定 + 20 种子｜流水 2.0 万｜付费 250｜评 25
- [ ] M5–6：达线则改价 + 真人声｜流水 4.2 万｜付费 480｜评 40
- [ ] M7–9：周报 + 续订｜流水 7.2 万｜付费 850｜评 55
- [ ] M10–12：只加码转化最高的 1 个渠道｜流水 **10 万**｜付费 1100–1300｜评 70
- [ ] 某周付费率 **<10%**：停新功能，只改报告和付费墙
- [ ] 某周安装 **>800** 且付费 **<5%**：选题引错人，改选题
- [ ] **第 6 月末** 付费 <120 或流水 <1.5 万：不涨价、不投流，只留报告+一个渠道
- [ ] **第 12 月末** 流水 <6 万但付费率 >20%：加内容，产品不推倒
