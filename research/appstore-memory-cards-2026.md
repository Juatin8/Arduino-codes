# App Store 记忆卡片 App 调研（2026-09）

数据来源：中国区 / 美国区 iTunes Search API（2026-09-13）、各 App 商店页与官网。评分与评论数会随时间变化，以下为抓取当日快照。

## 1. 市场怎么分层

记忆卡片不是单一品类，App Store 上至少叠了四层：

| 层 | 代表 | 用户要什么 | 体量 |
|---|---|---|---|
| A. 词库应试 | 墨墨背单词、百词斩、扇贝、不背单词 | 现成考纲词表 + 抗遗忘 | 中国教育头部，墨墨背单词约 97.7 万评、4.85 分 |
| B. 通用闪卡 / SRS | 记忆卡片、年轮、闪卡、AnkiMobile、Quizlet、Brainscape、Noji | 自己做卡 + 间隔复习 | 中腰部；中国「记忆卡片」约 4.3 万评，Quizlet 美区 111 万评 |
| C. 云端 AI 制卡 | Knowt、Gizmo、Flashka、FlashRecall、StudyGlen、AI 背书匠 | PDF/拍照/YouTube → 自动出卡 | 2024–2026 新进最多，同质化严重 |
| D. 设备端 AI | SnapDeck AI、Willys、Lectures.AI | 不上云、离线生成卡片 | 几乎都是 2026 新上架，评分不足，用户量极小 |

中国搜「记忆卡片 / 闪卡」时，排名靠前的是 B 层独立开发者 + 考研工具，不是 Quizlet。美国搜 `flashcard` / `AI flashcards` 时，Quizlet / Knowt / Gizmo / Brainscape 占搜索位。

## 2. 功能分布（按出现频率）

对约 40 款上架产品做关键词对照（商店描述 + 官网），按「几乎标配 / 常见 / 稀缺」归类。

### 2.1 几乎标配（>70%）

- 正反卡、翻转复习
- 某种间隔重复（多数写「艾宾浩斯」，实际是固定日程或简化 SM-2）
- 打卡 / 连续天数 / 热力图
- iCloud 或账号云同步
- 图文卡、提醒通知
- 免费下载 + 订阅解锁（词量、卡数、去广告、AI 额度）

### 2.2 常见（30–70%）

| 功能 | 谁在做 | 备注 |
|---|---|---|
| 按卡调度的真 SRS | Anki（FSRS）、墨墨 MM/MMX、RemNote、Mochi、StudyGlen 等 | 商店文案常写「艾宾浩斯」，不等于没有现代算法 |
| 社区 / 共享牌组 | Quizlet、记乎、墨墨记忆卡、Brainscape、Noji | 中国偏考研/公考卡包 |
| OCR / 拍照录入 | 闪卡、记乎 Plus、记忆卡、各类 AI 制卡 | 多数只 OCR，不理解内容 |
| PDF / 文档导入 | 闪卡、MarginNote、Knowt、Gizmo、Flashka | 导入 ≠ 自动出高质量卡 |
| Anki `.apkg` 导入 | 记忆卡片、闪卡、Anymo、拾光背诵、StudyGlen、Willys | 导入后算法常被改写 |
| 挖空 / cloze | 年轮、闪卡、记乎、RemNote、Anki | 医学/考研刚需 |
| 多学习模式（配对、测验、听写） | Quizlet、Knowt、Brainscape、Willys | 国产通用卡偏「翻卡+提醒」 |
| 云端 AI 出卡 | Knowt、Gizmo、FlashRecall、StudyGlen、Sticky、Scholarly | 2026 最卷赛道 |
| 笔记+卡片一体 | RemNote、MarginNote、年轮、闪卡、Noolingo | 学习曲线更高 |

### 2.3 稀缺（<15%，多数 <5%）

| 功能 | 现状 | 稀缺原因 |
|---|---|---|
| **设备端 / 本地 AI 制卡** | SnapDeck、Willys、Lectures.AI；开源 Anghkooey / CardGenie | 依赖 iOS 26 + Apple Intelligence 机型；中文区几乎空白 |
| **无账号 + 数据不出设备** | Anki Green、SnapDeck、Mochi（偏本地优先） | 大厂靠账号做订阅和增长 |
| **离线也能生成卡片** | 仅设备端 AI 能做到；StudyGlen 明确写「生成必须联网」 | 云模型成本更低、效果更好卖 |
| **AI 卡片 grounded 到原文页码/时间戳** | Scholarly 等少数云产品强调 | 多数 AI 卡会幻觉 |
| **漏一天不惩罚的调度** | Anghkooey 提 grace-first / freeze | 打卡产品反而用 streak 惩罚 |
| **医学级 image occlusion（本地）** | Anki 插件成熟；移动端原生少 | 实现重，Anki 生态已占位 |
| **真正增量阅读（incremental reading）** | SuperMemo 桌面强，iOS 弱 | 交互复杂，难卖给大众 |
| **敏感材料可用**（医案、内部讲义、未公开课件） | 几乎只有本地优先产品能承诺 | 云 AI 要上传原文 |
| **中文考纲词库 × 通用闪卡 × 本地 AI** | 没有完整产品 | 墨墨只做词，通用卡不做词库，AI 卡都在云上 |

## 4. 未实现或明显稀缺的需求

按「需求真实、供给少、2026 技术刚好能做」排序。

### 4.1 本地 AI 制卡（最大缺口）

现状：搜 `AI flashcards` 的前 15 名几乎全是「上传 PDF → 服务器大模型」。StudyGlen 自己写明：复习可离线，**生成必须联网**。Cognicard / Flashcards World 隐私页写的是把文本发给 OpenAI。

已上架的本地方案只有个位数，且：

- 评分均为「不足以显示」
- 绑定 Apple Intelligence（iPhone 15 Pro 及更新 + iOS 26）
- 中文输入/中文考纲场景几乎没人打透
- 卡片质量（原子性、不泄露答案、贴原文）没有公开评测

可做的差异：

1. **中文课堂材料本地出卡**：手写笔记、课本拍照、考研 PDF，不上传。
2. **双模式**：有 Apple Intelligence 走 Foundation Models；老设备走「只 OCR + 模板」，绝不偷偷上云。
3. **生成后必经编辑**：本地模型更容易出废卡，需要 grounded 检查（答案必须能在原文找到）。
4. **买断或本地额度**，避免「每张卡扣积分」。

### 4.2 隐私与数据所有权

中国头部全部账号 + 云 + 第三方 SDK。医学生、律师、企业内部培训、中小学作业（含个人信息）不能安心上传。

稀缺组合：**无强制账号 + SwiftData 本地 + 可选私有 iCloud + `.apkg`/CSV 完整导出**。Anki 能做到但体验差；Anki Green 做到离线但不会做卡。

### 4.3 调度算法本身不是缺口（更正）

初版把「商店没写 FSRS」当成「FSRS 稀缺」，这是错的。见文末勘误。

- 国际认真做 SRS 的产品正在收敛到 FSRS：Anki、RemNote、Mochi、SiYuan，以及官方 [awesome-fsrs](https://github.com/open-spaced-repetition/awesome-fsrs) 上的一长串实现。
- 中国用户量最大的记忆产品墨墨，用的是同源更完整的 MM / MMX，不是「没有现代算法」。
- 中国独立「记忆卡片 / 年轮 / 闪卡 / 记乎」确实多为固定艾宾浩斯或 SM-2，但这是腰部文案与实现落后，不是品类空白。
- FSRS 有 MIT 库（ts-fsrs / fsrs-rs / Swift 等），接入成本低，**不能当差异化卖点**。

还值得做的只剩体验层：默认开、少配置、漏一天不崩盘。不要把「我们有 FSRS」写成主宣传。

### 4.4 制卡税仍然在

用户真正讨厌的是**做卡**，不是翻卡。云 AI 解决了速度，引入了隐私和幻觉。本地 AI 若只做「一键 50 张」，会和 SnapDeck 撞车。

更稀缺的是制卡质量：

- 一张卡一个考点
- cloze 不剧透
- 医学图 occlusion
- 公式 / 文言文 / 法条专项模板
- 从「一段讲义」生成**复习队列**，而不是一堆问答垃圾

### 4.5 其它仍空着的点

- **教室 / 地铁无网生成**：云 AI 全军覆没。
- **手表 / 锁屏只复习、手机才制卡**：拿捏单词等在试，但没有和本地 AI 卡组打通。
- **家庭或宿舍局域网共享牌组**：不经过公司服务器。
- **中文 TTS / 发音完全本地**：背单词 App 音频多要联网缓存。
- **解释「你为什么忘」**：结合复习日志的本地小模型，而不是再开一个云聊天。
- **教师布置但不收集学生原文**：学校刚需，现有班级 PK 都要上传。

## 5. 不建议再做的功能

已经红海，除非有 10 倍体验，否则不要当主卖点：

- 又一个艾宾浩斯提醒笔记本
- 又一个云端「PDF 变闪卡」订阅
- 又一个考研共享卡包（记乎、墨墨记忆卡已占）
- 只做打卡 / XP / 徽章（所有新 AI 卡都在堆）
- 宣称 Anki 兼容却不能导回 `.apkg`、复习历史丢失
- 把「我们有 FSRS」当主卖点（算法已是开源标配）

## 6. 结论：相对能打的切口

若做新 App，2026 最空的交集是：

> **中文优先的通用记忆卡 + 设备端 AI 制卡 + 数据默认本地**（调度用现成 FSRS/MM 系即可，不构成壁垒）

三句话定边界：

1. 不做墨墨那种封闭词库，做「任何要记的东西」。调度不要自研，接入 FSRS 即可。
2. 不做 Quizlet/Knowt 那种上传即出卡，AI 只在设备上跑，老设备降级为手动/OCR。
3. 不做 Anki 的配置地狱：捕获（拍/贴/分享扩展）→ 本地草稿卡 → 人改 10 秒 → 进入复习队列。

验证指标建议：飞机模式能否从一张讲义照片生成并开始复习；导出 `.apkg` 能否在 Anki 桌面无损打开；中文手写/教材拍照的废卡率。

## 8. 勘误：FSRS 并不稀缺

初版（2026-09-13 上午）把 FSRS 列入稀缺功能，依据是约 40 个商店描述里很少出现「FSRS」字样。这只能说明**文案**，不能说明**实现**。

更正后的判断：

1. **算法不稀缺。** FSRS 开源，Python/Rust/TS/Swift/Kotlin 都有官方或社区库。Anki 内置；RemNote、Mochi、SiYuan、StudyGlen、Willys、KaChiKa 等已接入。
2. **中国更不稀缺。** FSRS 本身就是墨墨论文里 DHP 模型的开源简化版。墨墨背单词用 MM，墨墨记忆卡用 MMX；墨墨文档写明 MM / MMX / FSRS 是同一类记忆算法的产品版与社区版。
3. **仍成立的窄结论：** 中国 App Store 搜「记忆卡片」排在前面的独立 App（记忆卡片、年轮、闪卡、记乎）多数卖固定艾宾浩斯，没有宣称 FSRS。这是腰部产品的实现/营销落后，不是「市场没有现代 SRS」。
4. **方法局限：** 没反编译、没跑复习日志对照，无法证明某 App 后台是不是套了 ts-fsrs。Quizlet 等也从未在商店页写算法名。

产品含义：不要把 FSRS 当未满足需求。真正更空的是本地 AI 制卡和数据不出设备。

## 9. 个人开发者：十万元量级怎么切（考研上岸）

目标按净收约 10 万计，Apple 抽成后大约要 12–14 万流水。买断比订阅适合考研（考完即卸）：

| 定价 | 大约要多少付费用户 |
|---|---|
| ¥68 买断 | 1800–2100 |
| ¥128 买断 | 950–1100 |

**不要做：** 通用记忆卡片、云端 PDF 变闪卡、公共课词库（政治 / 英语 / 数学已被墨墨等占死）、把 FSRS 当卖点。

**入手点：专业课，不是公共课。** 每校每专业教材不同，大厂做不深；指定书和学长笔记很多人不敢传云 AI。上岸经验用在「哪些点值得做成卡」，不是再做一套题库。

第一版只做一条工作流：

1. 拍或导入一章指定教材 / 真题 / 笔记
2. 本地成卡，强制人改；模板用考研专业课：名词解释、简答框架、对比、易混点
3. 对外三堆：**今年必背 / 滚背巩固 / 考前压缩**（底层用现成 FSRS，不讲算法）
4. 只带一个已上岸专业的「必背清单」当种子卡包，证明懂行

无账号、能导出 `.apkg`。商店副标题写场景（如「XX 专硕专业课」），不写「考研神器」。一个专业、暑假 + 九月两季，800–1200 付费即可到账。第二个专业复制模板，不重做 App。

最小验证：找 20 个该专业考生收 ¥68。收不到钱是切口错了，不是功能少了。
