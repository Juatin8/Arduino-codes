# App Store 言语康复训练 App 调研：功能分布与稀缺需求

调研日期：2026-09-13  
样本：中美/港区 App Store 公开页 + 产品站 + 综述文献，共 **22 款**代表性应用  
范围：言语/语言康复训练（含失语、构音、口吃、帕金森、听障语训、儿童构音）。AAC 沟通辅具仅作对照，不计入“训练 App”主样本统计。

> 结论先行：训练 App 高度集中在「跟读/卡片/命名 + 进度条 + 订阅」。真正稀缺的是 **普通话成人神经性言语康复、方言/声调级反馈、生活迁移、沟通伙伴训练、障碍语音专用识别、硬件闭环**。

## 1. 市场怎么分层

| 分层 | 代表产品 | 谁在用 | 商业模式 |
| --- | --- | --- | --- |
| 成人神经康复（循证大库） | Constant Therapy、Cuespeak、TalkPath、Tactus 系列、nyra | 中风/TBI/失语/失用/痴呆 | 订阅或一次买断 |
| 儿童构音/语言发育 | Articulation Station Hive、Speech Blubs、米声、启音在线 | 家长 + SLP | 订阅 / 引流线下 |
| 发音 AI 纠音（听障/构音） | 雀说语训、repeech、音书语训 | 听障、CI 术后、构音不清 | IAP / 订阅 |
| 流利度 / 音量 | DAF Pro、Speak Up for Parkinson's、SpeechVive | 口吃、帕金森 | 买断或硬件配套 |
| 方言/小语种治疗 | SpeechOn（粤语） | 粤语失语/构音/口吃 | 免费+内容迭代 |
| AAC（对照，非训练） | Proloquo2Go | 无口语或严重不清 | 高价买断 |

中国区上架的「能独立完成训练」产品，儿童测评+机构获客（米声、启音）明显多于成人失语重症方案。英语区则相反：成人失语产品成熟，儿童以构音钻练和视频模仿为主。

### 3.2 中英对照差异

| 维度 | 英语区 | 中文区 |
| --- | --- | --- |
| 成人失语深度 | 高（Constant / Tactus / Cuespeak） | 低，缺对标产品 |

## 4. 用户与文献里反复出现的缺口

来源：App Store 评论、JMIR 2020 成人语训 App 质量综述、2025 慢性失语平板自学系统综述、中文失语沟通伙伴训练综述、Mandarin anomia 设计研究。

1. **卡片正确 ≠ 能说话。** 自学 App 对训练项目有效，泛化到自发口语很少。会话、叙事、电话/视频通话练习极少。
2. **通用 ASR 听不懂障碍语音。** Speech Blubs 甚至不听孩子说什么，只奖励「尝试」。严重构音/失语需要障碍语音模型，不是普通普通话识别。
3. **只打分、不教改。** 雀说因「给出具体意见」被汉语教师点名表扬，同时被批声调不准、只能中国手机号登录、无英文界面。
4. **家人不会当治疗助手。** 中文 CPT（沟通伙伴训练）有临床证据，几乎没有 App 化：提示策略、等待时间、是/否问题、降低认知负荷。
5. **订阅疲劳 + 价格墙。** Hive 家长约 $10/月；雀说被评贵。老人中风家庭对「练不完就停更」敏感。
6. **无障碍不足。** 偏瘫单手、视野缺损、失语友好 UI（大按钮、少文字、可语音操控）多数未声明辅助功能。
7. **证据与商店星级脱节。** JMIR：MARS 质量分与用户星级几乎无关；游戏化元素少，老年友好的游戏化更少。

## 5. 未实现或明显稀缺的需求（按机会排序）

### P0 供给真空，需求明确

| 需求 | 为什么稀缺 | 做什么才算补上 |
| --- | --- | --- |
| **普通话成人神经性言语康复套件** | Constant/Tactus 无中文临床深度；RecoverBrain 偏认知游戏 | 命名 / 听理解 / 朗读 / 书写 / 句子，按西方格、严重度分级；家人照片词库 |
| **声调 + 声韵母可解释反馈** | 普通话康复刚需；现有 AI 多给 0–100 分 | 「三声掉成四声」「送气不足」，口型/舌位对照，不是分数 |
| **障碍语音 ASR** | 通用识别对中重度构音接近不可用 | 针对构音/失语微调；不确定时改「近似/请家人确认」而不是判错 |
| **生活迁移课** | 训练停在词卡 | 点餐、就诊、坐地铁、微信语音、叫亲属；用用户自家照片（iName It 中文化） |
| **沟通伙伴训练** | 文献有、产品无 | 5 分钟教家属：少追问、给选择、复述确认；和患者课绑定 |

### P1 有产品但薄，可做成差异点

| 需求 | 现状 | 差异化 |
| --- | --- | --- |
| 方言与双语 | 仅粤语 SpeechOn | 先做「普通话 + 一种方言切换」；外籍护工/南方老人 |
| 治疗师–家庭闭环（中文） | 机构 App 封闭 | 独立 SLP 布置作业、看录音、改目标，不绑单一连锁 |
| 会话级练习 | Hive 有会话图，多数没有 | 有脚本的对话 + 延迟提示 + 录像自评 |
| 帕金森中文响度/音高 | 英文音量条、荷兰 Voice Trainer | PLVT/LSVT 式实时音量+限高音，大号表盘 |
| 离线 + 老人 UI | 部分离线 | 单手、高对比、无登录也能练当天课 |
| 买断/家庭套餐 | 订阅为主 | 6–12 周疗程包，符合康复周期 |

### P2 垂直小众，竞品接近零

- 腭裂/共鸣：鼻音计或麦克风估鼻音能量，消费级未见。
- 嗓音障碍：Voice Analyst 只可视化，没有结构化发声卫生课。
- 口吃中文：DAF + 缓说 + 焦虑暴露；iOS 专业产品弱。
- AAC 与口训并行：训练 App 几乎不接符号沟通。
- 群体/病友会话：综述认为 PWA↔PWA 互动利于泛化，App 不做。
- **传感/硬件闭环**：口型摄像头、喉麦、气流量、CI 调试数据。消费 App 几乎不接传感器。本仓库已有 ESP32 拾音（`esp32_SoundCollector_wifi`），若做语训，硬件侧是空白带。

## 6. 不建议再做的红海功能

单独做下面这些，很难赢过存量：

- 又一个儿童跟读词卡 / 贴纸游戏（Speech Blubs、米声已占家长心智）
- 又一个英语失语百万题库（Constant / TalkPath）
- 只有总分、没有纠错路径的「AI 打分」
- 纯线下机构招生壳（测评 3 分钟 + 电话销售）
- 不听真实发音的视频模仿（已被点名）

## 7. 若做新产品：最小差异组合

一条可落地的切口（中文成人，补全球最大供给洞）：

1. **评估**：图片命名 + 听词指图 + 朗读声韵调，3 层严重度。
2. **训练**：当天 15 分钟；目标词来自「我家相册 + 高频生活词」。
3. **反馈**：障碍语音模型；输出可解释的声母/韵母/声调错误；口型对照。
4. **迁移**：同一目标词出现在点餐/打电话脚本。
5. **家属**：每次课后 2 条 CPT 提示（「等 5 秒再提示」）。
6. **治疗师**：可选，看录音和正确率，不强制订阅才能练基础课。

儿童侧若做，应避开视频模仿红海，做 **声调/送气可解释纠音 + 家长不会的家庭迁移任务**，并诚实标注「不能替代 SLP」。

## 8. 方法与局限

- 依据 2026-09 各区 App Store 产品页、厂商站、JMIR / Brain Sci 综述、公开评论。未逐一下载做盲测，语音识别真实准确率以厂商宣称与评论为准。
- 中国区大量「语训」是机构 CRM，功能统计时已降权。
- 评分样本小的产品（SpeechOn 2 个、repeech 1 个）不代表疗效。
- 安卓-only 或 PC 听能软件（天使语训等）未计入 iOS 分布。

原始打点：[feature-matrix.csv](feature-matrix.csv)
