# 猫耳计划 ASO 优化（可直接贴进 App Store Connect）

现状：名称只有「猫耳计划」，描述还在招「语言学习者」。搜「听能训练」出来的是英语 App；搜「人工耳蜗 训练」**0 条结果**。空位在，元数据没用上。

Apple **会计入搜索**的：名称、副标题、关键词字段（各语言分开）。  
**不计入搜索**：描述、更新说明、截图上的字、评论正文。  
截图和评分影响的是 **点进来之后下不下载**，以及有评价之后的排序。

限制：名称 30 字、副标题 30 字、关键词 100 字（逗号分隔、**逗号后不要空格**）。名称/副标题/类别里出现过的词，**不要再写进关键词**。

---

## 1. 中国区（简体中文）直接用这套

### 名称（14/30）

```
猫耳计划-耳蜗助听器听能训练
```

保留「猫耳计划」方便老用户搜到；后半段抢 **耳蜗 / 助听器 / 听能 / 训练**。不要改成纯「听能训练」这种泛词，审核和区分度都差。

备选（更短、更偏开机）：`猫耳计划-人工耳蜗听能训练`（13 字）。若用这条，关键词里就不要再写「人工耳蜗」，改写「助听器」。

### 副标题（12/30）——不要重复名称里的词

```
噪声电话言语识别与听力图
```

名称已有耳蜗/助听器/听能/训练，副标题补 **噪声、电话、言语识别、听力图**。

备选：`开机后听不清每天都能练`（转化向，词更弱）。先用功能词，评分起来后再 A/B。

### 关键词（96/100）

名称+副标题已占：猫耳、计划、耳蜗、助听器、听能、训练、噪声、电话、言语、识别、听力图。下面不要再出现这些。

```
人工耳蜗,听障,语后聋,语训,听力测试,声调,空间听觉,乐器,单音节,环境声,弱听,听力障碍,纯音,听不清,言语测听,调机,佩戴,错题,日常用语,重听,方位,感音,开机,饭馆,地铁,家人,进步
```

不要写：猫耳FM、科利耳、利耳、雀说、天使语训、App、免费、最好（商标/废话，有拒审风险）。

### 推广文本（170 字内，**不用提审**，可随时改）

```
开机或新配助听器后，听得到但听不清？按噪声、电话、声调练，7 天出进度曲线，报告能发给康复老师。不能替代面诊和调机。
```

### 描述（不参与搜索，只转化）

第一屏必须让耳蜗/助听器用户对上号，删掉「语言学习者」。

```
给人工耳蜗和助听器使用者的听能训练。听得到、听不清时，从单字、噪声、电话声练到空间方位，每天十几分钟。

【适合谁】
• 耳蜗开机后的适应期
• 新配/重配助听器，噪声下跟不上
• 电话、饭馆、家人说话听不清
• 想把训练记录发给康复老师

【练什么】
单音节字词 · 噪声干扰 · 电话声模拟 · 乐器音色 · 空间方位 · 情景语句
练完有历史曲线和错题，复测能看见进步。

【小工具】
听力测试、听力图记录、环境噪声检测。

本应用提供训练与记录，不能替代医疗机构的诊断、调机和康复治疗。
```

### 类别

主类保持 **教育**。若还能选第二类别：优先 **健康健美**，不要先改「医疗」（审核更严，对搜索帮助有限）。

- 复测变好、或连练 3 天，再弹系统评分。
- 20 个种子用户：免费年费换 1 条真实评价（别写好评脚本，别集中同一 Wi‑Fi 刷）。

## 6. 两周改完，之后怎么验

**第 1 周（一次提审）：** 名称、副标题、关键词、描述、截图 1–3、推广文本。  
**第 2 周：** 预览视频、英语元数据、求评开关。  
**每 4 周：** 只动副标题或关键词里 3–5 个词，方便看是哪次生效。

App Analytics → 获取 → 来源 = **App Store 搜索**：

- 展示次数、产品页查看、下载、转化率
- 能看到的搜索词：优先盯 `人工耳蜗` `听能训练` `助听器康复` `耳蜗训练` `听力康复`
- 展示涨、下载不涨 → 改截图 1 和副标题  
- 词完全没展示 → 名称/关键词还没吃到，或评分太少

不要为搜「猫耳」优化。那个词是猫耳 FM 的。

## 8. 和 10 万流水的关系

ASO 负责把「已经在搜耳蜗/听能」的人接住，不是主引擎。  
主引擎仍是小红书/社群；商店页要让点进来的人 **5 秒内知道这是耳蜗训练，不是英语听力、也不是广播剧**。元数据按上面改完，才谈得上搜索贡献那 15% 安装。
