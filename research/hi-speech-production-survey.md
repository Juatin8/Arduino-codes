# 听障「说」专项：产出训练功能分布与缺口

调研日期：2026-09-13  
范围：听障 / CI / 助听器用户的 **言语产出**（构音、声调、清晰度、自我监测）。听能训练见 [hearing-impaired-rehab-apps.md](hearing-impaired-rehab-apps.md)。  
样本：商店在售 + 明确在用的产出工具 12 个。

> 听障的「说」不是听常儿童构音课换一层皮。CI 反馈不了音高，擦音听不清，元音空间更糊。商店主流是 **跟读 + 总分 + 口型 GIF**。真空在 **实时调形对照、元音 F1–F2、擦音高频能量、可懂度（不是音素匹配）、普通话舌位矢状面**。

---

## 1. 听障「说」难在哪（产品要对上的病）

系统综述（Mandarin CI 儿童产出）：辅音尤其 **擦音** 更差；**元音空间更小、更糊**；声调尤其 **T2 / T3**；调形更平、四声椭圆重叠。植入越晚、经验越短，调形越分不开。

长期机制（Frontiers 2019）：CI 对 F0 反馈差，部分用户会 **越戴越平（monotonizing）**——喉部少调，因为自己听不出变化。外人提醒很难纠正，需要 **看见自己的调**。

语前聋儿童：从零建音位和声调范畴。  
语后聋成人：音位还在，清晰度和韵律垮，要防 rumble / 过响 / 调域收。  
两边都不能只用「跟读像不像标准男声」。

| 临床问题 | 听障为何会这样 | 商店现在怎么对付 |
| --- | --- | --- |
| 擦音 s / sh / x / f | 高频 CI 弱或助听器听不清 | 口型正面（看不出舌沟） |
| 送气 p-b、t-d | 时域线索弱 | 偶有文字说明 |
| 元音空间挤 | 共振峰听不清 | 几乎无 F1–F2 图 |
| 声调 T2/T3、调域窄 | F0 不进处理器 | 雀说宣称纠声调，用户评不准 |
| 三声用气声硬凑 | 听不到低凹 | 无调形模板 |
| 越说越平 | 多年无效听觉反馈 | 无长期 F0 极差监测 |
| 可懂度低 | 音素对了句子仍含糊 | 只报正确率 |
| 口鼻共鸣 | 自我听不到鼻漏 | 消费级 0 |

## 2. 反馈有 6 层，大多数停在第 2 层

| 层 | 用户得到什么 | 代表 | 对听障够不够 |
| --- | --- | --- | --- |
| 0 只奖励开口 | 说了就过 | Speech Blubs | 否，孩子乱叫也过 |
| 1 一个分数 | 0–100 / 星 | 音书、米声 | 不知改哪 |
| 2 指出错音节 | 「二声偏了」「送气不足」 | 雀说（宣称） | 有用，依赖模型准不准 |
| 3 对立最小对 | 妈/麻 对照听+说 | 几乎无完整课 | 听障刚需 |
| 4 实时声学对照 | F0 曲线、元音点、摩擦噪声 | Voice Analyst 只有音高音量 | **课纲是真空** |
| 5 可懂度 | 陌生人听懂几成 | 无消费级 | 康复金标准，App 不做 |

雀说是唯一走到第 2 层、还声称面向听障的中文 iOS 产品。第 4–5 层没有和普通话课绑在一起的。

## 3. 产品分层（只看「说」）

| 层 | 代表 | 给听障什么 | 缺什么 |
| --- | --- | --- | --- |
| 听障向纠音 | [雀说语训](https://queshuo.cc/) | 音→词→句、口型/口腔动画、听辨→跟读、可解释纠音、情景对话 | 声调不准；无 F0 曲线；登录墙；贵 |
| 通用跟读打分 | 音书语训、米声 | 拼音/词/句/文打分；儿童朗读测评 | 为听常或沟通 App 附带，不懂 CI 错误模式 |
| 英语舌位示教 | [Speech Tutor](https://apps.apple.com/us/app/speech-tutor/id424752543) | 透明侧面/正面、腭位、自拍对照；NHS 有用于听障 | **英语音位**；无声调；无自动评分 |
| 声学仪表 | [Voice Analyst](https://apps.apple.com/us/app/voice-analyst/id732245213) | 实时音高/音量，买断 | 无音位课、无普通话四声模板 |
| 视频模仿 | Speech Blubs | 儿童口型示范 | **不识别孩子实际发音** |
| 机构口肌/课程 | 启音在线 | 口肌、门店、发音评测 | 招生壳，不是家庭闭环 |
| 科研 / Demo | 聪聪开口、Blue Voice、ViSTAFAE | 亲子示范、音高游戏、声道侧视 | 未成可用商店产品 |

| 功能 | 有 | 占比 | 判断 |

| ASR 或打分 | 7 | 58% | 多数一层分数 |
| 正面口型 / 视素 | 7 | 58% | 擦音、舌位仍看不见 |

| **可懂度（听者模型）** | 0 | 0% | 无 |
| 鼻音 / 共鸣反馈 | 0 | 0% | 无 |

## 5. 用户和文献对「说」的缺口

**评论 / 现场**
- 雀说：聋人「每天练、学会很多词」——证明 **可解释纠音** 比光打分值钱；同时声调不准、贵、中国手机号。
- Speech Blubs 被点名：不听孩子说什么。
- Speech Tutor：治疗师用于听障看舌位有效，但要人在旁边，App 自己不判对错。
- Voice Analyst：诊所喜欢仪表，家庭听障不知道今天该练哪四个调。

**不该用普通 ASR 当金标准**
听障产出常「音素对、调不对」或「调靠时长大对、音质不对」。通用识别听成别的字就判零，或听对字但句子不可懂仍给高分。需要：  
近似可接受带（听障常模，不是播音员）；不确定就「请家人听一句」。

**HVPT 听训能改善产出调形**（JASA 2024 声学证据），但那是 **听** 的协议漏到说。商店里的说课几乎不接这套。

## 6. 稀缺需求（只谈说）

### P0

| 需求 | 为什么稀缺 | 做成什么样 |
| --- | --- | --- |
| **目标调形 vs 自己的 F0** | CI 用户听不到自己平不平时 | 四声模板曲线；实时叠画；标出「三声没凹」「二声没升」 |
| **擦音可见** | 口型看不出 /s/ 舌沟 | 高频能量条或语谱一角；对照范本有没有「嘶」 |
| **元音点落在哪个格子** | 空间挤是综述结论 | 简易 F1–F2，目标圈 a/i/u |
| **听障常模，不是主播分** | 通用 ASR 误惩 | 按植入时长/语前语后分层；「可懂」优先于「标准」 |
| **T2/T3 最小对说** | 最难的两个调 | 连着听辨再产出，同一对词反复 |

### P1

| 需求 | 差异化 |
| --- | --- |
| 普通话矢状面 | Speech Tutor 的中文版：舌尖/舌面/软腭，慢放 + 自拍 |
| 可懂度抽检 | 每周 10 句，家人或模型打「听懂/听错字」 |
| 防 monotonizing | 每月音高极差；变窄就加「夸张四声」课 |
| 语前儿童 vs 语后成人 | 两套说课，不要一个卡通壳 |
| 情景里说 | 雀说有职业情景苗头；要接到微信语音/点餐，不是只单音节 |
| 家人确认通道 | ASR 没把握时让家属听 3 秒，避免挫败 |

### P2

- 鼻音计 / 麦克风估鼻能量  
- 送气时长可视化（p 的气爆）  
- 与听能课同一音位绑定（听完立刻说）  
- 硬件：气导/喉麦判清浊；更好的近讲麦。仓库 `esp32_SoundCollector_wifi` 可做稳定拾音 + 本地 F0，不走云 ASR

## 7. 不要再做

- 又一个 0–100 跟读  
- 不录音的视频模仿  
- 只正面嘴唇的「口型课」（擦音、舌根用不上）  
- 把口肌操当主产品（听障主问题是反馈，不是没练过嘴唇）  
- 英语 Speech Tutor 换皮但不做四声  

---

## 8. 最小切口（只做说）

**「看得见的普通话四声 + 三个单元音 + 一组擦音」**

1. 评估：读 妈麻马骂、a/i/u、si/shi/xi，出调形图 + 元音点 + 摩擦能量，不先报总分。  
2. 当天 10 分钟：4 分钟 T2/T3 最小对（看曲线说）；3 分钟元音点进圈；3 分钟擦音「有嘶」。  
3. 反馈层级默认 4，文字纠错当注释。ASR 只用来切音节，不用来当对错。  
4. 成人皮肤：仪表盘。儿童皮肤：同一套声学，换交互。  
5. 可选：家长听懂按钮，当可懂度弱标签。  
6. 成功指标：四声椭圆分开程度、元音三角形面积、家人可懂度；不要日积分。

和听能专项的关系：听课用 HVPT 喂同一批词，说课立刻产出来。两份报告可以是一个 App 的两个模式，不要做成两个互不说话的产品。
