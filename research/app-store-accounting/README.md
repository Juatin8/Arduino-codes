# App Store 记账 App 功能分布与缺口调研

调研日期：2026-09-13（第二轮扩样）  
范围：中国区 + 美国区 App Store 个人记账 / 预算类；对照安卓专属与行为干预  
样本：**42 款**（上一轮 24 → 本轮补 18）。覆盖率按 **34 款 iOS 记账主体** 重算（不含纯冲动干预、企业财务）。

结论仍然成立，但细节被精品和聊天记账改写了：

- **Cookie 记账** 是中国区「做的不错」的标杆：编辑推荐、4.9 / 1.6 万评、日预算 + 背敲快捷指令 + iCloud，**工艺完整，品类不新**。
- **MoneyThings** 是目前最接近「本地算习惯」的商店产品：端侧离群值，不是大模型。
- **飞鸭 / 团团 / 叨叨** 证明聊天记账能冲进财务榜，但助理是情绪搭子，不是节流引擎。
- 上一轮漏掉的 **iCost（4.9 / 10 万评，财务榜约 #40）** 说明：效率全家桶已经卷穿，再堆功能没有位置。

真正稀缺的组合没变：**本地习惯建模 + 决策前节流 + 能问账且默认不出端的助理**。Cookie 证明用户愿为手感买单；缺口仍在「记完之后拦得住」。

## 0. 本轮补进的关键样本

上一轮只盯随手记 / 钱迹 / 一木 / 薄荷 + 美区四大，漏了整层「小而美」和「聊天记账」。

### Cookie 记账（用户点名，做的不错）

中国区 **4.9 / 1.6 万评**，App Store 编辑推荐。北京不好奇。终身 ¥68 / 年 ¥30。

| 它强在哪 | 它仍然没有 |
|---|---|
| 手感：液态玻璃 + Material You、Emoji 图标、Watch / 小组件 / 后台模糊 | 习惯时序（只有报表和日/周/月预算） |
| 录入：截图 / 语音 / 拍照 / 文字，背敲三次快捷指令识屏 | 决策前拦截（用户靠「看清楚」少冲动，不是暂停层） |
| 日 + 周 + 月 + 分类预算，比多数国内 App 细一档 | 端侧 AI：商店写「AI 大模型」，走云端 |
| 无广告、无开屏、无理财；账本在 iCloud | 隐私标签仍有「用于追踪的标识符」 |
| 用户原话：养成习惯后冲动消费少了很多 | 共享账本弱于随手记；无银行同步 |

**对产品的含义：** Cookie 把「干净效率派」的体验做到了可买断、可迁移留学生、可 Watch。新产品如果手感弱于 Cookie、功能又只是 Cookie + 聊天，没有胜算。要比它多的是 **本地基线 + 花之前那一下**。

## 1. 市场分层（扩样后）

| 层 | 代表 | 卖点 | 用户换走的原因 |
|---|---|---|---|
| 全能老牌 | 随手记（4.9 / 67 万）、挖财（4.9 / 3.6 万） | 模板、家庭/生意、权限 | 臃肿、理财广告、会员 |
| 效率全家桶 | **iCost（10 万）**、钱迹（2.3 万）、一木（7250）、薄荷（5406） | 导入导出、快捷指令、资产 | AI 云端或浅层；手感不如 Cookie |
| **设计精品** | **Cookie**、可记、Budget Flow、MoneyThings | 原生感、买断、iCloud | 功能已够用，缺行动闭环 |
| 极简 / 养成 | 鲨鱼、喵喵、松鼠、Timi、团团 | 3 秒 + 宠物 | 语音填空、广告、导入烂 |
| **聊天记账** | **飞鸭**、叨叨、团团、Pick、咔皮 | 角色陪聊、一句话多笔 | 云端、情绪 > 洞察、会员贵 |
| 本地 / 开源 | 蜜蜂、Digits、Actual、一羽（WebDAV） | 数据主权 | 商店声量小或无中文习惯引擎 |
| 美区银行同步 | YNAB、Monarch、Copilot、PocketGuard、MoneyWiz、Simplifi | Plaid、净资产 | 同步断、贵、无语音 |
| 行为干预（非记账） | Axyom / PauseBuy / Not Yet / SpendShield | 开 App 前暂停 | **不读账本** |

中国区主路径仍是 **手动 + 微信/支付宝截图或 Excel + 快捷指令**。  
安卓另有 **小星式无障碍弹窗**；iOS 用背敲 / 识屏捷径勉强追，自动程度低一档。

## 4. 已饱和

扩样后红海更大，不是更小：

1. 记一笔 / 模板 / 秒开 / One Touch（MoneyThings、Cookie 模板）
2. 饼图趋势日历多账本标签
3. 月预算 80% 提醒、周期、退款报销
4. 微信支付宝导入（iCost 写 30+ 平台）
5. 小组件、快捷指令、Face ID、Watch（精品标配）
6. **「AI 大模型记一笔」** — Cookie、飞鸭、随手记、钱迹、薄荷、可龙同构
7. **聊天陪伴记账** — 飞鸭验证能上榜，后来者（Pick / 咔皮 / 团团）正在复制，窗口在关

用户差评仍是：坚持不下去、会员、导入格式、识别要改、广告。Cookie 评论里也有「后期功能变杂、和记账目的背离」——精品也会自己走进红海。

## 5. 稀缺与未实现（按扩样修正）

### 5.1 本地 AI 算习惯 — 不再是零，但仍浅

**已有残片：**

- MoneyThings：**本地**用离群值滤掉房租/人情，重算「日常均值」。千人千面，三个过滤等级。只作用于月初至今 / 近 1 个月，**不做周几×时段×商家聚类**。
- Copilot：per-user ML **分类**。
- 一木：年度热力图 = 记账频率，不是消费动机。
- 挖财「消费决策分析」、飞鸭「AI 图表」：事后可视化。
- Cookie：用户主观「看清了就少冲动」，没有模型。

**仍空：**

| 能力 | 谁最接近 | 差在哪 |
|---|---|---|
| 时序聚类（周四加班外卖） | MoneyThings 日均值 | 无场景维度 |
| 冲动 vs 计划 | PauseBuy 开 App 统计 | 不连账本 |
| 基线漂移（咖啡 18→32） | 无 | 预算红条不是斜率 |
| 可解释端侧 | MoneyThings 离群 | 只解释「这笔太大」 |

新产品若只做「另一个离群值」，是在打 MoneyThings 的已占格。要做的是 **离群 + 时间/App/情绪回写**，并喂给节流。

### 5.2 个性化节流 — 日预算有了，拦截还没有

| 形态 | 谁 | 局限 |
|---|---|---|
| 月÷日 显示 | 飞鸭、Cookie 日预算 | 不管周末/发薪日/个人方差 |
| 周预算 | Cookie、iCost | 仍是定额 |
| 信封剩余 | YNAB、Goodbudget | 用户自己看 |
| 现在还能花 | PocketGuard | 要银行同步；中国区难复制数据源 |
| 开购物 App 暂停 | Axyom / PauseBuy | **零账本** |

记账主体里 **购买前拦截仍为 0**。Cookie 用户「少冲动」来自意识，不是闸门。飞鸭日预算来自算术，不是基线。

可做且没人占住的组合不变：本地基线 → 今日可花（带置信区间）→ Screen Time 暂停层引用这条基线 → 忍了/买了回写。

### 5.3 语音 — 精品也是云端填单

| 层级 | 扩样后代表 |
|---|---|
| L1 填空 | 鲨鱼、部分养成 |
| L2 一句话 | Cookie、一木、挖财、iCost 捷径 |
| L3 多笔 | 飞鸭、可龙、蜜蜂 |
| L4 免开 App | Cookie 背敲、一木/挖财/钱迹捷径 |
| L5 端侧 + 问账 | Digits；美区头部仍无语音 |

Cookie / 飞鸭把 L2–L3 做成了好用的云端体验，**抬高了「再做语音」的门槛**，没有消灭 L5。离线、说完即记可撤销、语音问「还能不能买」仍稀缺。

### 5.4 AI 助理 — 拆成两条赛道

| 赛道 | 代表 | 缺口 |
|---|---|---|
| 情绪陪伴 | 飞鸭、叨叨、团团 | 不节流、账出站、会员 |
| 查询财务 | Monarch、Spendly、蜜蜂 MCP | 不执行 |
| 主动异常 | Copilot 2026 | 事后 |
| 录入生成 | Cookie / 随手记 AI 页 | 表单 |

空白仍是：**本地检索 + 规则/小模型回答 + 显式允许才出站 + 能触发节流文案**。  
不要再做一只会损的鸭子——飞鸭已经证明这能留存，也证明这不是财务增量。

## 7. 产品机会（对照 Cookie）

Cookie 证明：**把红海功能做准、做干净、做成日预算，就能拿到编辑推荐和买断**。  
它没有证明「习惯 × 节流」被做完——评论里的少冲动是副作用，不是产品机制。

仍建议押互锁三件，但把 Cookie 当体验下限：

```
手感 ≥ Cookie（快、素、iCloud）
        +
本地习惯（MoneyThings 离群只是第 0 步）
        → 个性化节流（数字 + 暂停层）
        → 语音/助理只作为口，默认可离线
```

**不要做：** 第二只飞鸭、第二份 Cookie 功能清单、云端万能 CFO、中国区重银行同步。

**MVP 对照竞品：**

1. 本地账本 + 可选 iCloud（对齐 Cookie / MoneyThings，不要自有账本云）
2. 录入达到 Cookie 的截图/语音/文字，默认端侧；云模型开关
3. 第 0 步就做 MoneyThings 没做的：**周几 × 时段 × 分类基线**（8 周）
4. 首页一个数：今天还能花（飞鸭日预算的个性化版）
5. 可选暂停 1–3 个购物 App，文案引用第 3 步
