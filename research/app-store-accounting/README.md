# App Store 记账 App 功能分布与缺口调研

调研日期：2026-09-13  
范围：中国区 + 美国区 App Store 个人记账 / 预算类；对照开源与行为干预类产品  
样本：18 款主流 + 6 款新锐 / 邻接品（冲动消费干预、本地优先）

结论先行：**记账录入、分类报表、预算、周期账、共享账本已经高度同质化。**  
真正稀缺的不是「再做一个 AI 语音记一笔」，而是 **本地习惯建模 + 决策前节流 + 能问答也能守口的助理**。三者目前被拆在三类互不连通的产品里。

---

## 1. 市场分层

| 层 | 代表 | 卖点 | 用户换走的原因 |
|---|---|---|---|
| 全能老牌 | 随手记（CN 4.9 / 67 万评）、挖财 | 模板多、家庭/生意账、云同步 | 臃肿、广告/理财、会员复杂 |
| 干净效率 | 钱迹（4.9 / 2.3 万）、一木（4.8 / 7250）、薄荷（4.8 / 5406）、可记 | 无广告、导入导出、快捷指令 | AI 多为云端或浅层分词 |
| 极简娱乐 | 鲨鱼记账 | 3 秒记、养成 | 语音只是填空，广告/订阅重 |
| 美区银行同步 | YNAB、Monarch、Copilot、PocketGuard | Plaid 自动入账、净资产 | 同步 fragile、隐私、贵 |
| 2025–26 AI 新锐 | Spendly、Moneko、Digits、可龙 | 对话/语音/OCR | 功能浅、订阅墙、设备门槛 |
| 行为干预（非记账） | PocketGuard、Axyom/PauseBuy、Not Yet、SpendShield | 可花额度 / 开 App 前暂停 | **不记账，也不懂你的账** |

中国区因开放银行受限，主路径是 **手动 + 微信/支付宝截图/Excel 导入 + 快捷指令**。  
美国区主路径是 **银行同步**，语音记账反而更弱。

## 3. 已饱和：再做没有差异

这些功能商店页几乎人人写，用户当标配：

1. **记一笔**：自定义键盘、常用分类、模板、秒开
2. **看账**：饼图、趋势、日历、标签、多账本
3. **管钱**：月/年预算、80%/100% 提醒、周期账、退款/报销
4. **迁入**：微信/支付宝 Excel 或截图（中国区刚需）
5. **家庭账**：邀请码共享（权限深度随手记更强）
6. **小组件 / 快捷指令 / Face ID**

用户差评集中在：**记完坚持不下去、会员墙、广告理财、导出不完整、银行同步断、AI 识别要改两遍**。  
不是「功能不够多」，是 **摩擦高 + 记完没有行动闭环**。

## 4. 稀缺与未实现（按机会排序）

### 4.1 本地 AI 算习惯 — 几乎空白

现状：

- 多数「AI」= **云端 LLM 解析一句话 / 一张图**（钱迹用 DeepSeek/Qwen，超时降级本地规则；随手记/薄荷/可龙同构）。
- Copilot 的 per-user ML 只做 **分类**，不做习惯。
- Digits / YourDigits 强调 **on-device 语音+分类**，但分析仍是普通分类图。
- 一木写「识别在手机本地完成，不上传截图原图」，仍是 **录入 OCR**，不是习惯引擎。
- 国行 Apple Intelligence 进度不确定，不能把产品赌在系统大模型上。

缺口（可做、且商店里几乎没人讲清楚）：

| 能力 | 和现有报表的差别 |
|---|---|
| 时序聚类 | 「周四加班后外卖金额中位数 +18」而不是「餐饮占 32%」 |
| 冲动 vs 计划 | 同一商家：月初工资后 2 小时内 vs 购物清单内 |
| 基线漂移 | 咖啡从 18→32 的 8 周斜率，而不是超预算红条 |
| 同伴/场景 | 和某人 AA、某地铁站、某 App 打开后 10 分钟内下单 |
| 全端侧 | Core ML / 规则+小模型，账本不出设备；可解释：「因为这 3 条模式」 |

这是用户点名的「本地 AI 算习惯」。技术上不需要大模型，需要 **本地特征 + 可解释规则/聚类**。云端 LLM 反而有隐私和成本劣势。

### 4.2 个性化节流 — 记账和应用拦截是断裂的

现状：

- 中国记账 App：**静态预算 + 超支提醒**（钱已经花了）。
- PocketGuard：**In My Pocket / Leftover** = 收入 − 账单 − 目标 − 已花，给一个「现在还能花多少」。这是美区最接近「节流」的记账功能，中国区对标产品几乎没有。
- YNAB：信封剩余，靠用户自己看，没有场景拦截。
- Axyom Pause Layer、PauseBuy、Not Yet、SpendShield：**开购物 App 前暂停 / 24h–30d 冷静期**。它们 **不连账本**，不知道你这个月餐饮是否已经超基线。

没人做的组合：

```
习惯引擎（本地）
    → 今日可花 / 该类剩余 / 是否异常时段
    → 决策前：锁屏小组件数字 + Watch 轻点确认
    → 打开淘宝/美团/Temu 时：用 Screen Time 暂停层，展示「再买这杯就偏离咖啡基线 2.1σ」
    → 冷静期结束：回写「忍住/还是买了」到账本，强化模型
```

关键差异不是再做一个预算环，而是 **花之前干预，且干预文案来自你自己的基线，不是通用鸡汤**。

可落地的三档（由易到难）：

1. **动态日额度**：剩余可花 ÷ 剩余天数，按历史波动给置信区间（周末加权）。
2. **分类速度限制**：该类近 7 日斜率 vs 个人 8 周基线，超阈值才拦。
3. **场景节流**：特定 App / 时段 / 地理位置触发暂停层 + 一句话理由。

### 4.3 语音记账 — 有，但大多是假便利

覆盖率已到约 70%，但质量分层很明显：

| 层级 | 谁在做 | 用户感受 |
|---|---|---|
| L1 语音填空 | 鲨鱼、部分老产品 | 说完还要选手动分类、点保存 |
| L2 一句话解析 | 一木、挖财、随手记、可龙 | 「午饭 32」填好金额分类，**仍要确认** |
| L3 多笔拆分 | 可龙「吃饭 50，打车 20」 | 批量确认，仍少见 |
| L4 免开 App | 一木/挖财/钱迹 快捷指令、Siri | 识别不稳、国行 Siri 弱 |
| L5 端侧语音 + 查询 | Digits / YourDigits（Whisper on-device） | 「这周餐饮花了多少」少见；美区头部 YNAB/Monarch/Copilot **几乎没有语音** |

真正稀缺的语音不是「再接一层 ASR」，而是：

- **离线 / 端侧**：地铁、飞机、不想上传账单音频
- **说完即记 + 可撤销**：默认入账，3 秒内 Watch/动态岛撤销，而不是每次确认
- **语音问账**：消费结构、是否还能买、和上周比——助理入口而不是录入入口
- **方言 / 口语金额**：「三十来块」「AA 了」——公开测评里随手记识别常被抱怨

Appinn 横评用户原话：愿意单独为语音付费，但不要绑一堆会员功能。说明 **语音应可拆卖，且必须比表单快一个数量级**。

### 4.4 AI 助理 — 能聊，不能管，更不能本地管

| 类型 | 代表 | 缺什么 |
|---|---|---|
| 查询型 Chat | Monarch GPT-4、Spendly「钱都去哪了」 | 不执行、数据进第三方 LLM |
| 主动推送 | Copilot 2026 assistant beta（异常、退款、改分类，需确认） | 仍是事后；无节流 |
| 录入型「AI 记账」 | 随手记/薄荷/可龙长按 + 语音图 | 不是助理，是表单生成器 |
| 开源对话 | BeeCount + 智谱 GLM / MCP | 云模型；主流商店用户找不到 |

空白位：**账本本地检索 + 小模型/规则回答 + 需要推理时用户显式「允许本条出站」**。

助理最小可用集：

1. 问：这周比基线多花在哪
2. 告：再买就会触发节流
3. 记：语音/截图入账
4. 从不：自动转账、自动改预算（要确认）

Monarch 自己也承认：助理还停在 explain，到不了 act。这正好是新产品的界限——**建议 + 拦截，不碰资金划转**（合规也更干净）。

## 5. 其它值得盯的缝

| 缝 | 证据 | 为何还没被做满 |
|---|---|---|
| 隐私本地优先但仍好用 | 少数派吐槽广告/贷款；钱迹/一木吃到口碑；Digits 纯本地但无中文生态 | 云同步与「开发者看不见数据」难兼得 |
| 情侣账：分开资产 + 共享日常 | Parallect：未婚伴侣没有好方案 | 共享账本=合并，或 AA 工具=不预算 |
| 订阅发现 + 取消路径 | PocketGuard 美区；中国区只有周期账列表 | 微信/支付宝订阅分散，无系统 API |
| 情绪/冲动标签 | SpendShield 心情；记账 App 几乎不记「为什么买」 | 偏心理产品，和账本分裂 |
| Apple Pay / 支付后自动记 | Digits Shortcuts；中国区靠截图/双击背 | 支付封闭，只能捷径+OCR |
| 数据主权导出 | 用户要 Excel/标准账本，讨厌只能 PDF | 老牌用格式锁客 |

## 6. 产品机会收敛

如果要做一款 **2026 还能差出一层** 的 iOS 记账，不要再卷「多一种账本模板」。建议押三个互锁能力：

```
本地习惯引擎  →  个性化节流（数字+暂停层）  →  语音/助理只是这两件事的口
     ↑                      ↓
     └──── 每笔「买了/忍了」回写 ────┘
```

**不要做的：** 云端万能理财顾问、贷款广告、重银行同步（中国区）、和随手记比功能清单。

**建议 MVP：**

1. 本地账本（SwiftData / SQLite）+ 可选 iCloud，默认不上自有服务器  
2. 语音 / 一句话 / 截图 三种录入，默认端侧；云 LLM 仅用户打开开关  
3. 8 周后自动给出 3 条可解释习惯（无需大模型）  
4. 首页只留一个数：**今天还能花**（PocketGuard 思路 + 本地基线）  
5. 可选：对 1–3 个购物 App 开暂停层，文案引用第 3 步的习惯  

这四块在当前 App Store 上 **没有完整组合体**。单独每一块都有残缺竞品，组合本身就是差异。
