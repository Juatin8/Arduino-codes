# 第 5 层怎么实现：可懂度（陌生人听懂几成）

对应：[hi-speech-production-survey.md](hi-speech-production-survey.md) 反馈层级第 5 层。  
日期：2026-09-13

> **定义**：说话人想说的话，没听过他的人能还原多少。金标准是 **生听者听写对词比例**，不是跟读像不像播音员。  
> JCM 2025：Whisper Large V2 对 5 岁 CI/助听器儿童英语句的听写，和 3 个生听者 ICC > 0.9。这是「机器当生听者」，不是口语评测 API。

---

## 1. 先分清：第 5 层 ≠ 第 1–2 层

| | 第 1–2 层（商店在做） | 第 5 层（要做的） |
| --- | --- | --- |
| 问题 | 音发得标准吗 | **话听得懂吗** |
| 模型看到目标文本吗 | 看到（强制对齐 / 讯飞口语评测） | **不能看** |
| 输出 | 0–100、某音节错 | 「买饭」被听成「卖饭」→ 这句 50% |
| 听者 | 没有听者 | 生人 / 家人 / 当生人的 ASR |
| 失败模式 | 音素对、句子仍含糊，仍高分 | 正是要抓住这种 |

听障常「字对、调糊、句子不可懂」。用评测 API 会漏掉第 5 层。

---

## 2. 临床协议（产品按这个抄）

**材料**  
英语金标准是 BIT：4 张表 × 10 句，每句 2–6 词、儿童熟词（*The boy is under the table*）。  
普通话可对标 MSTMs「日常会话语句表」，或自建 BIT 风格 4×10 句（3–8 字、厨房/交通/亲属）。同周不重复同一张表。

**采集**  
1. 屏幕出图，治疗师/App 范读一句，用户跟说（不要让用户看着汉字念，否则变成朗读）。  
2. 近讲麦，16 kHz+，句前后留 1 秒静音，RMS 归一。  
3. 听者（人或机器）**只听、不看目标句**；最多再播 1 次。  
4. 听写；完全听不清标「×」。  
5. 计分：对上的关键词数 / 总关键词。中文主指标用 **字正确率**，WER/CER 作辅。  
   `可懂度% = 1 - (替换+删除+插入) / 参考字数`  
6. 同音字（他/她）算对。声调错但字对：第 5 层算对（「懂了」）；第 4 层再罚调。

**听者必须「生」**  
家人会高估（听习惯了）。ICS 第 7 题就是「陌生人能明白吗」。理想：从未听过该说话人的健听成人，每句至少 3 人。这就是商店不做第 5 层的原因——贵、慢、隐私。

---

## 3. 三轨实现（按成本）

```
用户跟说 10 句
        │
        ├─ 轨 A 家人盲听写     当天有数，偏高
        ├─ 轨 B 机器当生听者   可每周自动跑
        └─ 轨 C 生人听写       金标准，月抽或诊所
        │
        └─ 仪表：熟人% / 机器% / 生人% 分列，不合成一个假总分
```

### 轨 A — 家人盲听写（一周能上）

1. 用户录完，推给家属：只出播放键 + 输入框，**不显示目标句**。  
2. 家属打出听到的字，或点「完全没懂」。  
3. App 对齐参考句，出本周可懂度%。  
4. 每月加填 [ICS 中文版](https://cdn.csu.edu.au/__data/assets/pdf_file/0005/399965/ICS-Chinese-Traditional.pdf) 7 题（第 7 题=陌生人）。  

限制：熟人偏差。UI 必须写「请当没听过，不要靠猜日常」。

### 轨 B — 机器当生听者（可规模化）

做法对齐 JCM 2025，不要走口语评测：

1. **开环转写**：Whisper / FunASR Paraformer / SenseVoice，**不传参考文本**。  
2. 离线优先（该研究因隐私只用本地模型）。手机用 distilled/small；服务端可用 large。  
3. 和参考句算 CER。`机器可懂度% ≈ 100 - CER`。  
4. 温度 0、禁幻觉：空音频不要出整句。过短/过响先拒收。  
5. **上线前校准**：收 30–50 名普通话听障用户 × 10 句，3 个生听者 + 机器，算 ICC / Bland–Altman。英语 5 岁 CI 已 ICC>0.9；普通话儿童/语前聋成人必须自己标，不能直接抄。

不要用的：讯飞/腾讯「口语评测」（看见文本）、强制对齐音素分、PESQ/STOI（要干净参考，测的是信道不是说话人）。

### 轨 C — 生人听写（金标准）

- **诊所**：3 个没接触过该患者的人，耳机听写。  
- **App 池**：匿名句包发给其他家庭（每句 1 次、每人不超过 4 张表，防学舌）。换积分。  
- **众包**：只有过完伦理和音频脱敏才能做。

每句 3 人，取字正确率中位数。月 1 次即可，用来校准轨 B。

## 4. App 最小流程

```
每周一次「可懂度抽检」（与日常跟读课分开）
1. 抽一张未用过的 10 句表
2. 图 + 范读 → 用户跟说 → 本地保存
3. 立刻：轨 B 转写，出「机器听懂 6/10 句、字正确率 71%」
4. 家属：轨 A，当晚有效
5. 错字热图：哪类词常听错（数字、亲属、去声）→ 推回第 3–4 层课
6. 趋势：4 周滑动，不报日积分
```

界面只说人话：

- 「没听过你的人，大约 7 成字能对上」  
- 「家人能听懂 9 成（会偏高）」  
- 「这周『四声 + 擦音』句掉了」  

不要：「口语 86 分」。

## 5. 工程要点

| 项 | 做法 |
| --- | --- |
| 参考文本隔离 | 转写服务只收 wav，不收 txt |
| 中文切分 | 字 / 关键词双计；关键词表预标 |
| 儿童 vs 成人 | 儿童句短、图多；成人用生活句、微信长度 |
| 语前聋 | 跟读可能复述失败；允许「看图自说」但参考改成目标关键词集合 |
| 隐私 | 默认可懂度在端侧；上传需单独同意、30 天删原音 |
| 拒收 | SNR 过低、削波、时长 <0.4s 或 >8s（儿童句） |
| 校准闸门 | 未做完 30 人对照前，机器分只标「实验性」 |
| 和 4 层关系 | 同一句可再跑 F0/擦音；**分数分栏**，不加权混成一个 |

数据模型（每句一条）：

```
utterance_id, list_id, ref_text, keywords[]
audio_path, rms, duration
family_transcript, family_cer, family_blind=true
asr_transcript, asr_cer, asr_model, asr_saw_ref=false
naive_transcripts[3], naive_cer_median
ics7_monthly
```

`asr_saw_ref` 必须恒为 false，否则这层作废。

---

## 6. 落地顺序

**第 1 周**  
10 句表（自建 BIT 风）+ 家人盲听写 + ICS-7 + 离线 small 转写。文案标明机器分未校准。

**第 1–2 月**  
攒对照数据，算机器 vs 生人 ICC。ICC<0.75 就换模型或微调，不要对外当金标准。

**之后**  
匿名句池做轨 C；错字热图驱动第 4 层；成人加「微信语音长度」句。

成功标准：家人能每周做完；机器分与生人偏差稳定（Bland–Altman 大部分落在 ±10 个百分点）；用户看见的是「听懂几成」不是星级。

---

## 7. 依据

- Zhang et al., *J. Clin. Med.* 2025：AI 听写评估 CI/HA/健听儿童可懂度，Whisper Large V2 ≈ 生听者。  
- BIT（Osberger 等）：听障儿童句表。  
- MSTMs：普通话日常语句识别率材料。  
- ICS（McLeod 等，中文译本）：熟人/陌生人主观可懂度。  

未在普通话听障人群上复现 ICC；轨 B 必须本地校准。
