# 听障方向：App Store / 周边产品功能分布与缺口

调研日期：2026-09-13  
范围：听障、助听器、人工耳蜗（CI）的 **听能康复 + 言语产出**。字幕/手语交友/处理器遥控只作对照。  
上级报告：[app-store-speech-rehab-survey.md](app-store-speech-rehab-survey.md)

> 听障不是「再做一个跟读 App」。商店里 **听** 和 **说** 是两条几乎不相交的产品线。中文听能大库在 PC/微信，不在 App Store；中文说的 App 几乎不练听。最大空白是 **听–说闭环 + 普通话声调 + 家长 AVT + 不绑品牌的 iOS 听能课**。

---

## 1. 临床路径（产品应对不上）

听障康复要同时走两条阶梯，商店产品通常只占其中一段。

**听（Erber）**  
察觉 → 辨别 → 识别 → 理解  
日常检查：Ling-6（/m, a, u, i, ʃ, s/）覆盖低到高频。普通话还要 **四声**。CI 不显式编码 F0，声调长期是硬骨头。

**说**  
因听觉反馈弱：共鸣、送气、声调轮廓容易漂。需要口型 + **可见基频**，不是普通 ASR 打分。

**谁练**  
儿童：AVT 强调家长是第一责任人，先听后看口型。  
成人语后聋：开机后自我矫治 + 噪声/电话。  
语前聋大龄：期望值与康复条件决定上限。

Cochrane 对 AVT 疗效证据偏弱，但不改变现场共识：辅具只给声音，不教怎么听、怎么说。

## 2. 产品怎么分层

| 层 | 干什么 | 代表 | 听障康复？ |
| --- | --- | --- | --- |
| A 听能训练 | 环境声、音素对比、噪声下选词 | Hearoes、i-Angel Sound、Cochleo、eargym CI、Hear Coach、天使语训(PC)、利耳听训(微信) | 是，**只听不说** |
| B 言语产出 | 跟读、口型、打分 | 雀说语训、音书「语音训练」 | 是，**只说不听** |
| C 沟通辅具 | 字幕、TTS、手语视频 | 音书主功能、Ava、系统实时字幕 | 否，代偿 |
| D 设备控制 | 换程序、电量、丢处理器 | Nucleus Smart、HearCare | 否 |
| E 厂商教育 | 文章、生活技巧 | Cochlear CoPilot | 弱训练 |
| F 测评导流 | 3 分钟评测 → 线下 | 米声、启音 | 部分发音，非 CI 听能体系 |

中国听障家庭的真实工具栈经常是：厂商 App 调机 + 微信听训 + 机构课 + 偶尔下一个纠音 App。没有一款 iOS 产品把听、说、家长策略串起来。

中文语训：雀说是听障向唯一像样的 iOS 纠音，但仍是「说」产品。

## 5. 用户和文献里的缺口

**商店评论**
- i-Angel Sound：卡死、无声、蓝牙/直连切换把词截断。听能 App 的生死线是 **稳定进 CI 的音频**，不是题量。
- Hearoes：开机几天「还是蜂鸣但分数高于瞎蒙」→ 需要给语后聋成人的信心设计；2026 改计分后觉得没成就感。
- 雀说：聋人「每天练、学会很多词」；汉语教师要可解释纠错；声调检测不准、中国手机号登录。

**研究（对产品的含义）**
- 家用电脑听训能提高普通话儿童的声母/韵母/**声调**识别，且能保持约 2 个月（Fu 等，Angel Sound 路线）。
- 高变异语音训练（HVPT，多话者）提高 CI 儿童声调知觉，并可改善产出的调形可分性（JASA / JSLHR）。**商店没有把 HVPT 做成完整普通话产品。**
- CI 不编码 F0，声调靠时域包络；所以「只打分」没有用，要练 **听包络 + 看自己的音高曲线**。
- 诺尔康康复手册：儿童「1+集体 + 个别 + **家庭**」；成人最好自我矫治。App 几乎不教家长怎么在厨房里做 AVT。

## 6. 稀缺需求（按机会）

### P0 听障专用真空

| 需求 | 现状 | 做成什么样 |
| --- | --- | --- |
| **听–说闭环（同一音位/声调）** | 听能 App 不录音；纠音 App 不按 Erber 升级 | 先最小对立听辨（妈/麻/马/骂），再跟读，再叠自己的 F0 曲线和范本 |
| **普通话声调 HVPT** | 论文 5 次课有效；App 几乎无 | 多话者、多音速；从单音节到词；保留 10 周复测 |
| **中文 iOS 听能大库（不绑品牌）** | 天使语训在 PC；利耳在微信且完整版邀码 | 声韵调 + 环境声 + 噪声句 + 电话频带；Android/iOS 同等 |
| **进处理器的可靠音频** | 第一差评原因 | 检测直连/MFi/蓝牙；失败则禁止开练并指导；可选外放校准 |
| **可见基频（说）** | 没有消费级 | 实时 F0 曲线；CI 用户看自己有没有把三声拐下去 |

### P1 有需求、产品薄

| 需求 | 差异化 |
| --- | --- |
| 家长 AVT 日课 | 每天 8 分钟：先遮嘴说、等反应、指耳朵、归位头件；不要变成机构招生 |
| 开机 0–12 周路径 | 语后聋成人 vs 语前聋幼儿两套；避免一套「儿童游戏」打发成人 |
| 噪声 / 微信语音 / 电话 | 可调 SNR；微信语音是中文真实场景，英语 App 没有 |
| Ling-6 每日自检 | 连续失败 → 提示「先查头件/电量/线，再怨自己」 |
| 自家声音库 | 爸妈/老师录音当刺激，比播音腔更迁移 |
| 买断/疗程包 | Hearoes $10/月；听障康复是年计，不是娱乐订阅 |

### P2 垂直、竞品接近零

- 音乐/旋律（CI 弱项，天使语训有 PC 模块，手机几乎无）
- 双模式 HA+CI、单侧植入
- 调机前后对比：同一套听辨题，给听力师看
- 手语 + 口语双路径（现有 App 默认口语法，排斥手语家庭）
- **硬件闭环**：喉麦/气导、口型相机、环境声采集。本仓库 `esp32_SoundCollector_wifi` 可做「真实环境声进听辨课」或「自己嗓音的 F0 可视化」，商店里没有。

## 7. 不要再做

- 又一个字幕/会议转写（音书、系统实时字幕已占）
- 又一个品牌处理器遥控
- 又一套英文环境声游戏（Hearoes 已在、i-Angel 已烂）
- 只打总分的跟读
- 3 分钟评测导流线下中心
- 绑死单一 CI 品牌的题库（换机就废）

---

## 8. 若只做听障：一条最小切口

**「普通话 CI/助听器：声调听辨 → 可见 F0 跟读」**

1. 评估：Ling-6 + 声韵调最小对立 + 一句噪声句。  
2. 当天 12 分钟：6 分钟 HVPT 听辨（多话者），6 分钟跟读，屏幕叠范本/自己的音高。  
3. 音频：优先直连 CI；失败则停，不假装在训练。  
4. 家长（儿童档）：两条 AVT 提示，不强制看口型。  
5. 不绑品牌、可离线当天课。  
6. 指标：声调识别率 + 调形可分性（可对标 JASA 那套声学分析），不要只报「今日积分」。

儿童游戏化和成人语后聋要分皮肤，不要做成一个卡通壳。

## 9. 方法与局限

依据 2026-09 App Store 页、科利耳/诺尔康公开材料、JASA/JSLHR/PMC 听训研究。未逐一下载做 CI 直连实测。微信/PC 产品计入分布，是因为它们才是中文听能的实际供给。利耳听训完整版权限未核验。
